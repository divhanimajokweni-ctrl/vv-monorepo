How to apply (UP repo)
Target repo: https://github.com/divhanimajokweni-ctrl/you-are-the-lead-systems-engineer-responsible-for-generating-code-for-the-ubuntu-pools-platform.-you (Per‑app GitOps — Argo watches the UP repo)

Unzip into the UP repo root:
unzip up-overlays-argocd-pack-20260316.zip -d .

git add .

git commit -m "chore(up): add Helm overlays (dev/prod) + ArgoCD Applications + governance"

Replace <LB_IP> in:
overlays/helm/up/dev-values.yaml → api-dev.up.<LB_IP>.nip.io
overlays/helm/up/production-values.yaml → api.up.<LB_IP>.sslip.io
Create Argo Applications (Per‑app GitOps):
kubectl apply -n argocd -f argo/app-up-dev.yaml

kubectl apply -n argocd -f argo/app-up-production.yaml

ArgoCD will watch the UP repo on main, syncing the helm chart with the specified valueFiles.

Open a PR and paste PR_BODY.md as the description.
