Okay, let's get the foundation of your **Helm** structure and the **Image Tag** automation set up directly in your Replit environment. This will bridge the gap between your code and the ArgoCD manifests you just packaged.

### 1. The Helm Core (`/helm`)
Since the ArgoCD manifests expect a Helm chart at `helm/`, we’ll create a clean, parameterized base.

**Create `helm/Chart.yaml`:**
```yaml
apiVersion: v2
name: safegrid-brain-api
description: Brain API for Vision and Alerts
type: application
version: 0.1.0
appVersion: "1.0.0"
```

**Create `helm/values.yaml`:**
```yaml
replicaCount: 2
image:
  repository: ghcr.io/safegrid/brain-api # Update to your actual registry
  pullPolicy: IfNotPresent
  tag: "latest" # This will be automated

service:
  type: ClusterIP
  port: 80

resources:
  limits:
    cpu: 500m
    memory: 512Mi
  requests:
    cpu: 100m
    memory: 128Mi
```

### 2. Environment Overlays (`/overlays`)
Following your package's logic, we need the `dev` and `production` specific values.

**Create `overlays/helm/up/dev-values.yaml`:**
```yaml
replicaCount: 1
resources:
  limits:
    memory: 256Mi
# Dev-specific env vars (e.g., sandbox API keys)
extraEnv:
  NODE_ENV: development
```

### 3. Automated Image Tagging (The "SHA" Strategy)
Instead of using `tag: main`, we’ll use a Git SHA. This ensures ArgoCD actually sees a change in the manifest and triggers a sync.

I’ve drafted a small **Bash script** you can run in your Replit shell to "release" a new version to Dev.

**Create `scripts/bump-version.sh`:**
```bash
#!/bin/bash
# Get the current Git SHA (short version)
NEW_TAG=$(git rev-parse --short HEAD)

echo "Updating Dev image tag to: $NEW_TAG"

# Use yq (standard in most dev environments) to patch the dev-values.yaml
# If yq isn't installed, we can use a simple sed command:
sed -i "s/tag: .*/tag: \"$NEW_TAG\"/" overlays/helm/up/dev-values.yaml

echo "Done. Commit these changes to trigger ArgoCD."
```

### 4. OpenAPI Live Docs
To make the `docs/openapi.yaml` useful immediately within Replit, I recommend adding a simple route to your API that serves the spec or a Swagger UI.

**In your main API file (Express/Node example):**
```javascript
const express = require('express');
const swaggerUi = require('swagger-ui-express');
const YAML = require('yamljs');
const swaggerDocument = YAML.load('./docs/openapi.yaml');

const app = express();
app.use('/docs', swaggerUi.serve, swaggerUi.setup(swaggerDocument));
```
