# Mixer Component Analysis

## Overview
The Mixer component provides central audio mixing controls with crossfader, channel faders, and master controls.

## Key Features
- 2-channel mixing with crossfader
- Individual channel EQ controls
- Master volume and cue system
- PFL (Pre-Fader Listen) monitoring
- Booth output monitoring

## Audio Routing
- Channel input selection
- Send/return for effects
- Master output with limiter
- Separate booth and main outputs

## State Management
- Channel levels and panning
- Crossfader curve adjustment
- Master section controls
