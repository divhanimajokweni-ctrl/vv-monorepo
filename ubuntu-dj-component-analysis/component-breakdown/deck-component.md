# Deck Component Analysis

## Overview
The Deck component manages individual audio tracks with playback controls, cue points, and integration with the broader UbuntuDJ mixing system.

## Key Features
- Track loading and management
- Play/pause/cue controls
- Waveform integration
- BPM and key detection
- Sync with other decks

## Props & State
- Audio file handling
- Playback state management
- Cue point storage
- BPM synchronization

## Integration
- Audio engine connection
- Lindiwe AI for beat matching
- Crossfader positioning
