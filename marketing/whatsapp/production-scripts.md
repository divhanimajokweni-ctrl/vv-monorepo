# ✅ Ubuntu Pools — WhatsApp Campaign Scripts (Production Ready)

**Purpose:** User onboarding, engagement, trust transfer
**Tone:** Human, respectful, Ubuntu‑aligned
**Channel reality:** WhatsApp groups + 1‑to‑1 forwarding

---

## 🔹 Campaign 1: Champion‑Led Introduction (Primary Onboarding)

**Sender:** Village chair / treasurer / respected member
**Goal:** Curiosity → Safe participation

```
Hi family 👋

We're trying something new as a group this month.

It's a short pool‑management game that shows how we handle late payments,
emergencies, and tough decisions — without risking any real money.

I played it myself and learned a lot.

If you want to try it:
👉 [LINK]

No payments. No paperwork. Just learning.
```
